ShotBox Support

ShotBox is a macOS menu bar app for watching your screenshot folder, renaming new screenshots, and moving them into folders you choose.

Email: gyeonho@gmail.com

Common Topics

  • Selecting or reselecting the screenshot watch folder
  • Adding quick-move destination folders
  • Renaming a screenshot before or after filing it
  • Restoring a moved screenshot back to the watch folder

Folder Access

ShotBox only watches and moves files in folders you explicitly select. If a folder was renamed, moved, or removed, open ShotBox settings and select that folder again.
